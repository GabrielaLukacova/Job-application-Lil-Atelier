# Lil’ Atelier application — private preview
Open this folder in VS Code, then open index.html or run `python3 -m http.server 8000` and visit http://localhost:8000.

The portrait uses the original external image URL, with 10% of its natural top height removed and no bottom cropping. To make it self-contained, place your actual portrait at assets/gabriela.png and update its src. CV and contact links were retained from the previous project. The selected work uses compact text links rather than unavailable project images. External assets and URLs require verification before publishing.

Do not publish until you approve. After approval create a separate GitHub repository Job-application-Lil-Atelier and enable Pages from main / root. No existing application is modified.
